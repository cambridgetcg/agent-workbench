# Agent Workbench 0.3.0

This release implements the seven integration stages identified in the
[Claude Code research](../research/claude-code-2026-09-25.md). The shared Python
core runs from either plugin; native authentication and permission settings
remain authoritative.

Verification covers 256 Python tests, plugin and skill validation, and
TypeScript checks for the optional frontend.

| Stage | Delivered behavior | Boundary |
| --- | --- | --- |
| Launch evidence | Record selected executable, version, help and capability evidence per attempt. | A wrapper child discovered through PATH is a candidate until runtime verification. |
| Configuration explanations | Show selected sources, instruction presence, hook and permission counts, and plugin cache/source drift. | Partial discovery; presence does not prove loaded context. |
| Public event timeline | Persist bounded session, tool, task, usage and control metadata while a task runs. | Private text, tool inputs and reasoning are excluded. |
| Native duplex controls | Address an active Claude/Astra task with deduplicated input or interrupt requests. | Receipt acknowledgment does not prove applied effects. Uncertain delivery is never replayed. |
| Parallel workflows | Schedule ready tasks with bounded concurrency, checkout leases and per-attempt Git worktrees. | Read-only is a declaration; worktrees use committed HEAD and retain results for explicit review. |
| Plugin evaluations | Plan and run bounded local with/without comparisons and report measured outcomes separately from context estimates. | No report publishing; list-price estimates are not actual charges. |
| Optional mod | Show a metadata-only status pane with explicit refresh and text fallback. | Separately loaded, gated by a compatible Claude runtime and its function-hook opt-in. |

## Observed native verification

Live Astra smoke checks used an isolated, officially distributed Claude Code
2.1.282 binary selected through per-process PATH. Its distribution hash and code
signature were verified before use. The normal Claude installation was not
replaced.

- A single prompt completed after the native initialization handshake.
- Follow-up input was acknowledged, produced the expected reply marker, and
  drained using native result prompt UUID receipts.
- An interrupt request was acknowledged and the workflow ended as interrupted.
- The optional mod passed strict native validation and nine native tests.
  Checks without function-hook opt-in and against the older installed runtime
  correctly reported unsupported host testing.

These checks establish the tested protocol paths, not exhaustive compatibility
with all versions or wrappers. Older streams without consumed-input receipts
get only a narrow single-input completion fallback. Ambiguous overlapping input
remains unverified until an explicit stop or deadline.

## Lifecycle verification

The independent review found eight lifecycle and isolation issues; installation
was held until fixes and a second review completed. Regression coverage now
includes controller SIGTERM/SIGKILL, durable checkout claims before native or
Git-hook execution, cross-run worktree removal, simultaneous pipe backpressure,
final event-drain cancellation, incomplete EOF frames, complete local plugin
payload changes and reserved request-ID collisions. The follow-up review found
no remaining concrete blockers in those paths.

## Local evaluation smoke evidence

The recovery case ran once per arm with deterministic output-contract graders.
The plugin arm invoked the Workbench skill and passed six of six scored checks;
the baseline passed one of six. Scores were 1.0 and 0.1667, respectively. Native
reported duration was 51 seconds total, with a $0.130572 list-price cost estimate
and no judge-model cost. No report was published.

This one pair verifies the evaluation path and a specific response contract. It
does not establish a statistically reliable improvement or prove unsafe baseline
behavior. The case did not execute operational commands or effects. Context
inventory estimates remain distinct from measured inference usage.
