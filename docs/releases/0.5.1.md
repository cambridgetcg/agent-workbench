# Agent Workbench 0.5.1

Follow-ups from the first real runs of 0.5.0.

- Native launches, plugin evaluations and mod checks no longer inherit a Codex
  host session's markers. Codex 0.156 sets `CODEX_CI`, `CODEX_SESSION_ID`,
  `CODEX_THREAD_ID` and `CODEX_VERSION` on every command it runs, so Workbench
  started from its Codex plugin passed the parent session's identity to each
  agent it launched. Also removed: `CODEX_TOOL_CALL_ID`, which newer Codex
  hosts set (reported by Codex's own review of this change);
  `CODEX_INTERNAL_ORIGINATOR_OVERRIDE`, Codex's counterpart of
  `CLAUDE_CODE_ENTRYPOINT`; and `CODEX_ESCALATE_SOCKET`, a channel back to the
  parent's approval handling. `CODEX_HOME`, credentials,
  `CODEX_SANDBOX*` and the network proxy variables are kept; a sandbox still
  binds the processes started inside it. The launch record lists the removed
  names, as for Claude Code's.
- `run` warns before starting, and records in its `run_started` event, when a
  pending Hermes task's `run_budget_seconds` is not shorter than the
  invocation's `--timeout` (default 1800 seconds). The run's hard stop would come
  first, so Hermes could never give its wrap-up notice. Tasks awaiting an
  explicit retry are not named, and an invalid limit still gets the usual error.
- The handoff Markdown summary now names each task's execution settings (model,
  effort, adapter, workspace, base_ref, sandbox, timeout, Hermes turns, skills and
  budget), escaped as untrusted text, on one line, with control and format
  characters (including bidi overrides) replaced. Prompts and argv remain in the
  JSON only.
- The Git helper safety tests no longer fail on a loaded machine. Each test
  writes a new helper executable, and macOS checks a new file on its first launch,
  which could outlast the tests' short timeouts. The helper now runs once,
  untimed, before the timed checks, and the wall-clock bounds leave headroom
  while staying well below the waits they guard against. Under 40 concurrent
  copies on a 14-core Mac, the old tests failed every time and the new ones
  passed 80 of 80. The cost: a cleanup stall of a few seconds per Git call,
  which the 2-second bounds would have caught, now passes.

Codex's markers were observed with a live `codex exec` (0.156.1) that printed
variable names only.
