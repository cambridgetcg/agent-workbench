# Agent Workbench 0.6.0

A careful neighbour to AgentTool. Agents use AgentTool through their own
harness's MCP tools; Workbench makes no AgentTool call and holds no AgentTool
identity. This release keeps what belongs to one Collab session out of the agents
Workbench launches, refuses commands that would sign, send or take over, shows
which AgentTool tools each harness has, and releases PR #3's worktree changes.
See [AgentTool next door](../agenttool.md).

- Native launches, plugin evaluations and mod checks no longer inherit
  `AGENTOOL_COLLAB_SESSION_FILE`, `AGENTOOL_COLLAB_ALLOW_CURSOR_RECOVERY` or
  `AGENTOOL_COLLAB_CLAUDE_PID`. A child holding them would resume the launching
  host's Collab session, and Collab fences the earlier holder. The launch record
  lists the removed names. `AGENTOOL_COLLAB_DB`, the journal choice, stays.
- Command tasks may not run the AgentTool lobby CLI, any `room` command with
  `--lease` whatever the executable, Collab courier, `collab-zerone anchor`,
  hosted mission clients or workers, `agenttool-collab-host end`, or the personal
  `api.agenttool.dev/v1/wake`. Lobby signing needs a person typing yes at a real
  terminal, which launches never have, and lease sends need none. The check looks
  inside `sh -c` scripts and wrappers; plain `grep`, `git grep` and `git log` keep
  their words as data. It runs at create and import and again at launch, so a run
  saved earlier fails as `launch_error` with no process. It is a tripwire, not a
  sandbox.
- Collab session credential-file paths (`collab-sessions/<id>.json`, or an
  `AGENTOOL_COLLAB_SESSION_FILE` assignment with a path) are refused in names,
  goals, prompts, argv, `note` and `steer` text, without repeating the path.
  Agent summaries show `[Collab session file withheld]`; handoff export refuses
  such a run and continuity notes withhold such a note. A saved prompt that names
  one fails at launch rather than being rewritten.
- `doctor` ends with "AgentTool tools by harness": for Codex, Claude Code, Hermes
  and an astra-ultra Hermes profile, which of the public agenttool MCP (5 tools),
  the public canon MCP (search, fetch), Collab and the lobby's read-only view are
  configured, with allowlist fit and the Collab package version beside its
  configured entry. Servers are recognised by endpoint or command; other servers
  are only counted; names are reported, never values. For a missing public server
  it prints the exact command or snippet to add it, and applies nothing. It reads
  configuration files only: no process, network, Collab journal, session file or
  lobby command. Hermes `config.yaml` is read with a block-style subset reader.
- Hermes builds from mid-2026: their "N file(s) were NOT modified" footer now
  raises the failed-edit warning, as the newer "N file edit(s) FAILED" does. A
  task that sets `run_budget_seconds` fails at launch with a plain reason when
  the probed `chat --help` has no `--run-budget`, instead of reaching Hermes's
  argument parser.
- New [docs/agenttool.md](../agenttool.md) and
  [examples/collab-peer.json](../../examples/collab-peer.json): a separate native
  agent completes one Collab task into pending review with an explicit actor, a
  command task checks its file effect, and the parent reviews from its own
  session. Every example, including `examples/verify.json`, is now tested.
- From PR #3: `workspaces` measures `path_exists` and `dirty` now, next to the
  recorded values, and observes only the recorded checkout, not a replacement at
  its path. `workspace-remove` also accepts a clean tree whose HEAD is on a
  remote-tracking ref, recording `removal_basis` and `removed_head`.

Compatibility: no new task fields, so 0.5.x and 0.6.0 handoffs remain mutually
importable when neither carries a refused command or a session-file path. A run
saved earlier with either now fails at launch with no process, and its export
fails; a handoff carrying either is refused at import.

Verified on a Mac mini (macOS 15, Python 3.11.15): the full offline suite, a
read-only `doctor` against the Mac's real Codex, Claude Code and Hermes
configuration (configuration hashes, the Collab journal and the lobby state
unchanged before and after), refusals and environment withholding with command
tasks only, and the examples saved without running. No model was called.
